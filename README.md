Projeto - Tecnologia e Internet

Projeto acadêmico desenvolvido em HTML para apresentar conceitos básicos sobre tecnologia, internet e segurança digital.

Páginas

Início: apresenta o conceito de tecnologia e Inteligência Artificial.

História: mostra brevemente a origem da internet e a ARPANET.

Segurança: apresenta dicas básicas para segurança na internet.

Formulário: contém uma pesquisa com diferentes tipos de campos HTML.

Tecnologias utilizadas

HTML5

Imagens

Elementos semânticos do HTML

Praticar a utilização de diferentes elementos e recursos do HTML5 na criação de um site simples e informativo.
